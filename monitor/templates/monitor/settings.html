How to send real email

The app doesn't deliver email itself: it hands each message to an email (SMTP) server you have an account with, which delivers it. The easiest option is a Gmail account:

  1. Use a Gmail account (ideally one just for this) and turn on 2-Step Verification.
  2. Create an App Password at myaccount.google.com/apppasswords and copy the 16-character password.
  3. In the .env file in the project folder, set: 
    EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=true
EMAIL_HOST_USER=youraccount@gmail.com
EMAIL_HOST_PASSWORD=your16charapppassword
DEFAULT_FROM_EMAIL=youraccount@gmail.com
  4. Run docker compose up -d in the project folder, reload this page and click Send test email.

Using another provider (e.g. Brevo, Mailgun, SendGrid)? Use the SMTP host, port, username and password it gives you. The README has troubleshooting tips.
